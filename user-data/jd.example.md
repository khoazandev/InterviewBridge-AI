# Target Job Description — Backend Software Engineer

## About the Role
We are looking for a Software Engineer to join our international product team. You will collaborate with global stakeholders in English to design, build, and maintain scalable backend services.

## Responsibilities
- Design and maintain reliable backend APIs using Python or Node.js.
- Optimize relational databases (PostgreSQL/MySQL) and caching layers.
- Write clean, testable code and participate in code reviews.
- Communicate progress clearly in daily standups and cross-team meetings.

## Requirements
- 1–3 years of experience with Python (FastAPI/Django) or Node.js.
- Solid understanding of SQL, RESTful API design, and Git workflows.
- Good English communication skills for technical & HR discussions.
- Nice to have: Docker, CI/CD, Redis, cloud deployment experience.
